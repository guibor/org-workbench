#+TITLE: Org Workbench Requirements

* Purpose
Make original Org files first-class reading and editing documents in Codex,
with a portable browser edition and a public community repository.

* Requirements
- [X] Preserve original .org source; no Markdown round-trip.
- [X] Render headings, prose, lists, checkboxes, tables, links, code, and math.
- [X] Read, Split, and Source modes with a searchable outline.
- [X] Interactive TODO, checkbox, and table-cell editing.
- [X] Shared undo/redo and keyboard-accessible controls.
- [X] Conditional host saves, clean refresh, and dirty conflict protection.
- [X] Keep HTML, Babel, includes, and file-local configuration inert.
- [X] Local-first; no telemetry or remote image tracking.
- [X] Responsive light/dark reading typography inspired by MDF Reading.
- [X] Selectable MDF Reading, Nano-inspired, and Plain rendering profiles.
- [X] Adjustable typography, page width, and table density without source edits.
- [X] One-command, checksum-verified prebuilt installation with no sudo.
- [X] Prepare Reddit and announcement drafts; do not post them automatically.
- [X] Portable plugin manifest, Codex compatibility manifest, reproducible build.
- [ ] Confirm a full open/edit/save round-trip in the real Codex desktop host.
- [X] Publish the public GitHub repository: https://github.com/guibor/org-workbench

* Immediate Next Steps

- [ ] Consider recoverable drafts with explicit storage/privacy controls.

* Non-goals for 0.2
Org agenda, capture, formula execution, Babel execution, automatic inclusion,
lossy WYSIWYG serialization, and full parity with Emacs Org export.

* Changed Requirements
** Editable, not read-only
The previous feasibility proposal was a read-only viewer. The current request
explicitly replaces that with rendered interactions and source editing. The
original Org text remains canonical in both designs.
** Public community project
The user explicitly chose public GitHub visibility rather than an initial
private repository. Private notes and machine configuration must not be included.
** Configurable presentation and prebuilt installation
The original single reading profile is now the default among three profiles.
Appearance preferences may persist locally, but never document contents or paths.
The primary installation instructions now use a pinned prebuilt release rather
than requiring every reader to clone and compile. Source installation remains supported.
