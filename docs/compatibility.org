#+TITLE: Compatibility and Known Limits

* Supported
- Org headings, TODO keywords, priorities, tags, planning dates.
- Nested unordered/ordered lists and checkboxes.
- Org pipe tables, cells, numeric alignment, header rules, horizontal scrolling.
- Prose emphasis, code/verbatim, quote/example/source blocks, footnotes, math.
- Properties and drawers, collapsed by default.
- Internal heading links and in-file ID/CUSTOM_ID targets.
- HTTP(S)/mailto links, host-scoped relative file links and explicit raster images.
- Full source editing, exact rich-edit patches, undo/redo, host version checks.

* Deliberate Limits
- UTF-8 files up to 1 MiB; no encoding conversion.
- No Babel, table formula execution, includes, setup-file reads, or local variables.
- No Emacs TODO hooks, automatic CLOSED dates, dependency updates, or statistics cookies.
- Multiple TODO sequences are combined into a single cycle in 0.1.
- Tables do not evaluate formulas or interpret all alignment/column-group hints.
- Cross-file id:/denote: links require an external note index; not followed here.
- Absolute paths, directory escapes, file::search links, SVG and remote images are blocked.
- Local images are limited to 5 MiB and require a click to load.
- Browser import edits in memory and exports a copy; it cannot save the original.
- No autosave or persistent draft cache. Save/export before closing a file panel.
- Source editing handles all text; the renderer is not a full Emacs export engine.

* Host Support
File entrypoints and writable resource APIs depend on the host build. The
upstream MCP Extensions patterns document identifies desktop 26.928.20710 as
the baseline for the original extension set; this plugin checks resource and
write capabilities at runtime instead of relying solely on a version number.

An existing chat may report =unknown MCP server 'org-workbench'= immediately
after installation. Restart Codex or open a fresh chat with the plugin selected.
If a host omits writable metadata or an ETag, edits remain exportable but the
Save-original control is not offered.
